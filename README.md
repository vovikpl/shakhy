# Pair Play / Ігри вдвох

Chess, Sea Battle, Tanks, Racing, Maze Quest and Air Hockey for two players: on one phone,
or on two Android phones via Bluetooth or the same Wi-Fi network (no internet needed).

Шахи, морський бій, англійська, танчики, гонки, бродилка й аерохокей для двох гравців.
Мова інтерфейсу вибирається за мовою телефона (українська або англійська), перемикач є в меню.

Після кожного завантаження змін у **Releases** з'являються:
- `PairPlay.apk` — для встановлення на телефон напряму;
- `PairPlay-GooglePlay.aab` — для завантаження в Google Play Console.

Порти: TCP 50505 (гра), UDP 50506 (пошук ігор у мережі).
