# Ігри вдвох: шахи і морський бій

Шахи і морський бій для двох телефонів Android в одній Wi-Fi мережі (інтернет не потрібен)
або для гри вдвох на одному телефоні.

Готовий APK після кожного завантаження змін з'являється в розділі **Releases** цього репозиторію.

Порти: TCP 50505 (гра), UDP 50506 (пошук ігор у мережі).
